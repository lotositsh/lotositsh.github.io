Настройка OpenVPN на Oracle Cloud (Ampere aarch64) под Ubuntu 22.04

1. Настройка сети в Oracle Cloud (важно!)

Oracle Cloud блокирует трафик на уровне облака отдельно от iptables на самой машине. Нужно сделать это ДО настройки сервера:

В консоли Oracle Cloud зайти в Networking → Virtual Cloud Networks → ваш VCN → Security Lists (или Network Security Groups, если используете их)

Добавить Ingress Rule:

Source: 0.0.0.0/0

IP Protocol: UDP (или TCP, если выберете этот протокол)

Destination Port Range: 1194 (стандартный порт OpenVPN, можно любой другой)

Без этого шага OpenVPN не заработает, даже если всё остальное настроено правильно — это самая частая проблема именно с Oracle Cloud.
